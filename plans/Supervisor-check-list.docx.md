**Supervisor dashboard & checklist**

 

The supervisor dashboard has two tabs: Pre-boarding check-list (manager’s own pre-boarding to-dos, self-certified, no gamification) and New Hire Session (mission editor \+ new hire progress view). This section defines the Prepare tab content.

 

 

| Phase 1 — Before day 1  ·  Pre-boarding preparation |  |  |
| ----- | ----- | :---: |
| **✓** | **To-do item** | **When** |
| □ | Request system access for new hire via ServiceNow | *Day −7* |
| □ | Set up workstation (desk, monitor, keyboard, nameplate) | *Day −3* |
| □ | Order office key / access card | *Day −3* |
| □ | Define and document the day-1 schedule | *Day −2* |
| □ | Block calendar for welcome meetings on day 1 | *Day −2* |
| □ | Organise welcome lunch with the team | *Day −1* |
| □ | Set up new hire in MesseBuddy — assign missions from template | *Day −1* |
| □ | Assign buddy and fill in buddy card in app | *Day −1* |
| □ | Prepare induction plan document | *Day −1* |
